ISI FOLDER INI HANYA FILE YANG DIUBAH UNTUK DESAIN WHITE UI.

Cara pakai:
1. Backup project showroom lama.
2. Extract ZIP ini.
3. Masuk ke folder PERUBAHAN-WHITE-UI.
4. Copy seluruh isi folder tersebut ke folder utama project showroom lama.
5. Saat Windows meminta Replace, pilih Replace files in destination.

Jangan ada database, .env, vendor, node_modules, atau public/uploads di paket ini. Jadi file lama yang tidak termasuk perubahan tetap aman.
